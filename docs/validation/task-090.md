# task-090 实现验证记录

日期：2026-09-23。范围：已批准规格 `03aec94` 之后的 MVP 实现，提交分支 `bx/task-090`、PR #1。本文和原始数据与实现一起提交；浏览器正式构建由 [资源清单](task-090/bundle.json) 中的内容哈希文件名标识，依赖由根目录 `pnpm-lock.yaml` 固定。

## 实现结果

完成单账号登录、最近修改列表、新建、富文本编辑、自动保存、删除、同一账号多设备访问和本机草稿恢复。服务端采用 Fastify / Node.js 24；浏览器采用 React、Tiptap / ProseMirror 与原生 IndexedDB。Markdown 是唯一正文格式，元数据控制接口使用 JSON。没有搜索、数据库、索引文件、备份或历史版本。

编辑器原型先验证支持范围的内容往返，初始原型 JavaScript 为 202,822 字节 gzip，低于 256,000 字节预算，随后才扩展应用。最终构建包含完整页面、Markdown 转换和草稿逻辑；不依靠延迟加载排除必需代码。未使用 React Router / Dexie；普通 CSS 与系统字体避免额外字体请求。

本地存储采用同文件系统临时写、文件 fsync、原子发布和父目录 fsync。OSS 适配器包含唯一写入方约束、待确认操作持久化、状态卷身份绑定及热读取 HEAD 缓存。两种模式共享接口，正文只位于所选后端。

## 性能数据

测试机：Apple M4（10 核）、Darwin 24.6.0、Node 24.14.1，Chromium 153.0.8010.12（Playwright 1.63.0）。服务端与浏览器同机，不限制 CPU。使用约 2,000 个中文字符的笔记、生产资源和真实缓存头，CDP 模拟下行 10 Mbps、上行 2 Mbps、150 ms 延迟。冷样本使用新浏览器上下文，仅保留已建立的登录 Cookie；暖样本复用 HTTP 和 IndexedDB 缓存。

`pmem:ready` 位于正确内容导入及编辑器初始化之后。每次样本实际输入独立标记，查询 IndexedDB 确认完整内容，并在同步后刷新验证；同时报告“导航到首字真正保存”的更保守耗时，包含自动化动作调度。正文读取、Markdown 导入、编辑器初始化、本机提交分开记录；后两者有包含关系，不能简单相加。

最终数值与全部原始样本：[导航与本机保存](task-090/navigation.json)、[资源清单](task-090/bundle.json)、[列表扫描](task-090/list.json)。其中导航与列表分别在独立测试运行中采样。

| 场景（各 30 次，0 失败） | P50 | P95 | 最大值 |
| --- | --- | --- | --- |
| 冷打开 T_ready | 938.8 ms | 951.4 ms | 954.5 ms |
| 暖打开 T_ready | 434.1 ms | 445.0 ms | 933.6 ms |

从导航开始到实际首字完成本机保存，冷 / 暖 P95 分别为 993.7 / 494.9 ms；从输入事件到本机提交 P95 为 22.8 / 21.2 ms。首字必需 JavaScript 为 213,096 字节 gzip（208.1 KiB），CSS 为 2,453 字节 gzip（2.4 KiB），均在预算内。暖打开存在一次高于 500 ms 的样本，原始数据保留，按规格采用 P95 判定，不能把最大值隐藏成全部达标。

另以 `PMEM_BENCH_NETWORK=weak pnpm bench:web` 实测下行 1 Mbps / 上行 256 Kbps / 300 ms 延迟，冷、暖各 30 次、0 失败：[弱网原始样本](task-090/navigation-weak-2007.json)。冷打开 P50 / P95 / 最大值为 3171.7 / 3194.0 / 3194.4 ms，暖打开为 752.3 / 775.3 / 3205.8 ms。首字持久化的输入延迟 P95 为 22.1 / 20.6 ms。这一轮没有注入 1% 丢包，不算完整弱网验收；标准网络门槛不适用于这一组限速条件。

列表测试直接调用生产 `Notes.list`，包括全库元数据扫描、排序和当前页片段，不含 HTTP / 网络传输。1,000 篇 P95 为 12.4 ms，10,000 篇为 85.6 ms；每轮仅读 20 篇片段。所有 60 轮成功。列表延迟一期仅报告，不设置通过线；该结果不能代表 OSS 列表首屏。

最终导航统计在同目录 JSON 的 `summary` 中；页面就绪指标与首字持久化均须结合环境解释。当前桌面实验可以检查本机构建是否退化，不能直接宣布参考 Linux 服务器或手机硬指标验收完成。
